# Isolate project command environments from the web host

omp-web sanitizes environments inherited by its built-in project commands, project Git operations, and plugin update checks: `PORT`, `NODE_ENV`, `NEXT_*`, `PI_WEB_PASSWORD`, and `OMP_WEB_PASSWORD` are omitted. Git retains its configuration and runs with `LC_ALL=C`; plugin checks retain npm configuration and disable Git's interactive prompt. The agent `bash` tool preserves the SDK-managed PATH and session metadata; variables explicitly set by a project command still take effect. The built-in terminal retains the host environment except for both web login password variables. Skill commands additionally filter credential-like environment variables. Third-party extensions retain control of their own subprocesses; this policy is not a general sandbox for them.
